# Code of Conduct

This project is for collaborative, respectful, technically serious work.

## Our Standard

Participants are expected to:

- be respectful and constructive
- assume good faith while staying precise
- critique ideas, code, and behavior without attacking people
- help keep the project welcoming to newcomers and useful to operators

The following behavior is not acceptable:

- harassment or personal attacks
- hateful, discriminatory, or demeaning language
- doxxing or sharing private information
- disruptive conduct that makes collaboration unsafe or unproductive

## Scope

This code of conduct applies in issues, pull requests, discussions, and other project spaces.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that do not meet this standard.
